## Top projects — recommended order

Open in this order for the cleanest narrative.

### 1. [AI-Enablement-Toolkit](https://github.com/Automater89/AI-Enablement-Toolkit) — start here

**Why it matters:** This is the umbrella artifact. It bundles the templates, frameworks, and program references Wes uses to run enterprise AI enablement end-to-end. The README's recruiter reading path is designed for a 10-minute pass.

**What it proves:** enterprise enablement design, program packaging, companion-project orchestration, recruiter-readable documentation.

**Reference program outcomes (disclosed):** 29 courses, 11 sites, 1,000+ employees, 53% → 72% retained.

**Refreshed branch:** `readme/recruiter-audit-refresh` · commit `bc9d09b`

### 2. [ai-adoption-measurement](https://github.com/Automater89/ai-adoption-measurement) — the evidence loop

**Why it matters:** AI programs fail without measurement. This Python framework measures adoption *effectiveness*, not just usage — session completion, prompt quality, CSAT lift, voluntary engagement, and program-level evidence loops.

**What it proves:** measurement literacy, Python framework design, ability to instrument an AI program rather than just launch it.

**Reference program outcomes (disclosed):** 34 sessions, 9 sites, 1,019 attendees, 72% conversion, 3.0 CSAT, +380% YoY, 500+ prompts collected.

**Refreshed branch:** `docs/recruiter-readme-refresh` · commit `a5aa1b7`

### 3. [benefits-faq-agent](https://github.com/Automater89/benefits-faq-agent) — HR technology + RAG

**Why it matters:** A working RAG agent for employee benefits FAQ — the canonical HR-tech use case. Demonstrates RAG architecture, Azure AI Search, Azure OpenAI, Copilot Studio integration, HR privacy/governance, and human-escalation workflows.

**What it proves:** HR technology fluency, RAG patterns, Azure stack, Copilot Studio integration, governance-aware design.

**Refreshed branch:** `docs/recruiter-readme-refresh` · commit `4076cf6`

### 4. [process-waste-detector](https://github.com/Automater89/process-waste-detector) — Lean Six Sigma + AI

**Why it matters:** A Python/Azure OpenAI tool that applies Lean waste-detection to written process descriptions. Uses the *Expert-in-a-Prompt* pattern and explicit human-in-the-loop governance.

**What it proves:** Lean Six Sigma Black Belt fluency translated into an AI workflow, prompt-engineering pattern literacy, governance-first design.

**Refreshed branch:** `docs/recruiter-readme-refresh` · commit `13dbfa2`

### 5. [ai-readiness-assessment](https://github.com/Automater89/ai-readiness-assessment) — readiness scoring

**Why it matters:** Newly seeded. Shows the *front of the funnel* — structured readiness scoring, governance gate, stakeholder report, synthesis prompt, and responsible-AI guardrails.

**What it proves:** front-end program design, scoring frameworks, responsible-AI mindset. Treat as a promising signal of how Wes structures discovery work, not as a mature codebase yet.

**Seeded branch:** `docs/recruiter-facing-readme` · commit `c9e96765`
