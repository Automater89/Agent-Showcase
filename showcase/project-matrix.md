## How to read this matrix

- **Proof signal** — the one-line claim the repo backs up.
- **Tech stack** — concrete tools, not buzzwords. Bias toward what a senior engineer or platform lead would verify.
- **AI / automation pattern** — the *design pattern* (RAG, expert-in-a-prompt, evidence loop, readiness gate). Patterns transfer across roles; tools change.
- **Enterprise enablement angle** — where the work sits in an enterprise rollout (discovery, design, instrumentation, governance, workflow).
- **Business outcome** — disclosed outcomes only, or credible mechanisms phrased as such. No invented metrics.
- **Recruiter takeaway** — the hiring signal: what role profile this repo fits.
- **Status / visibility** — branch, commit, and visibility so you can verify quickly.
